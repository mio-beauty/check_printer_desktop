# check_printer_desktop

Windows‑клиент для печати: Electron (main) + React (renderer).

## Требования
- Node.js 20+

## Запуск в dev
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run dist:win
```

## Переменные окружения
- `BACKEND_URL` — URL backend для Socket.IO (по умолчанию `https://printer.backend.miobeauty.uz`)
