# SVG icons

Source SVG assets live in this folder.

Conventions:
- Prefer `24x24` viewBox (`0 0 24 24`).
- Use `stroke="currentColor"` / `fill="currentColor"` (avoid hardcoded colors).
- Keep paths optimized (no editor metadata).
- Name files in `kebab-case` (e.g. `warehouse.svg`, `printer.svg`).

Rendering:
- For UI usage prefer React wrappers from `src/components/icons/`.
