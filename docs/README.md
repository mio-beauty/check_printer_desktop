# Документация check_printer_desktop

Этот проект — Windows‑клиент печати: Electron + React UI + локальная печать ESC/POS.

## Навигация

- `docs/architecture.md` — архитектура и взаимодействие компонентов
- `docs/development.md` — как запускать и разрабатывать
- `docs/configuration.md` — настройки и переменные окружения
- `docs/printing.md` — как устроена печать (LAN/ESC-POS)
- `docs/testing.md` — тестирование без реального принтера (fake printer)
- `docs/releases.md` — сборка, релизы, автообновления (GitHub Releases → позже S3/CloudFront)
- `docs/troubleshooting.md` — частые проблемы и решения
- `docs/warehouse_queue.md` — очередь/сборка (склад) — QA сценарий
- `docs/warehouse_problems.md` — проблемные заказы (partial/failed) — QA сценарий
